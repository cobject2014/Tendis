PURPOSE: Fix Go dependency issues and ARM64 compatibility

CHANGES:
A. Added after 'go get integrate_test/util':
```bash
go mod tidy
go mod download
```

B. Added ARM64 syscall patch:
```bash
chmod -R u+w "$GOPATH/pkg/mod"
echo "Patching ngaut/log for ARM64 compatibility..."
TARGET_FILE=$(find "$GOPATH/pkg/mod/github.com/ngaut" -name "crash_unix.go" | head -n 1)
if [ -f "$TARGET_FILE" ]; then
    echo "Found file: $TARGET_FILE"
    cat "$TARGET_FILE"
    sed -i 's/syscall\.Dup2(int(f\.Fd()), 2)/syscall.Dup3(int(f.Fd()), 2, 0)/g' "$TARGET_FILE"
    echo "--- After Patch ---"
    grep "Dup3" "$TARGET_FILE" || echo "Patch failed? grep Dup3 returned nothing."
else
    echo "Error: crash_unix.go not found!"
fi
```

RATIONALE:
- go mod tidy: Ensures go.mod/go.sum consistency
- chmod: Go module cache is read-only by default, needs write permission for patching
- syscall.Dup2 → Dup3: Dup2 is not available on ARM64 Linux, use Dup3 instead
